# Calculator (Python)

## Description
Developed a calculator application in Python using Jupyter Notebook that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The project uses user input, conditional logic, and structured programming to execute operations dynamically.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input handling

## Concepts Used
- Functions
- Conditional statements
- Basic error handling

## How to Run
1. Open the notebook in Jupyter
2. Run all cells
3. Enter inputs when prompted
